How it works

Three steps. No installation, no account, and the internet doesn't need to be working.

  1. 1

    Plug in the USB

    Insert it into the Windows laptop that has the internet problem.
  2. 2

    Double-click "START-HERE"

    Open the USB drive and run it. The check takes about a minute and changes nothing.
  3. 3

    Say Yes to fix, then read your report

    If Internet Guardian can fix something safely, it lists exactly what it will do and asks first. Windows asks for Administrator permission only at that point. When it finishes, one report opens in your browser and a copy is saved on the USB.

What it can fix

Only common, safe causes. It always asks first, saves a backup, tests each fix, and can undo it.

  • Switch on a disabled network adapterWhen nothing is connected because Wi-Fi or Ethernet was turned off.
  • Start stopped network servicesThe Windows services that hand out addresses and detect the connection.
  • Ask the router for a new addressWhen the laptop never received a usable address.
  • Turn off a proxy that isn't answeringA working proxy is never touched, because a workplace may need it.
  • Correct a wrong clockSyncs the date and time so secure websites load again.
  • Remove suspicious lines from the hosts fileA copy of the original file is kept. Never done on computers joined to a work or school domain.
  • Clear the DNS cache and, if needed, use public DNSOnly when your DNS server has stopped answering but public DNS works. Never on computers joined to a work or school domain.

Rarely, a deeper fix is needed (resetting Winsock or the TCP/IP stack). Internet Guardian offers it only when the safe fixes didn't work, tells you first that it needs a restart and can't be undone, and checks the result after the restart.

Your result in one word

A score out of 100 and a status you can understand at a glance.

HEALTHYThe connection looks good.
ATTENTIONSomething deserves attention, such as a weak signal or a proxy.
CRITICALThe internet can't be reached, or there are serious problems.

The score describes the connection at the moment of the check. Problems outside the laptop — the router, the modem or the internet provider — can change it, and the report says so when that looks like the cause.

What Internet Guardian does

  • Finds the cause and explains every point lost
  • Works even when the internet is down
  • Asks before every fix and saves a backup first
  • Tests each fix, and can undo it
  • Saves the report and certificate on the USB

What it never does

  • Change anything without asking
  • Send your files or results to anyone
  • Need an account
  • Fix problems at the internet provider or in the router hardware

To test the connection it makes a few small requests to public servers, such as Microsoft's connection-test page and public DNS. No personal information is sent.

Questions people ask

The things that surprise people the first time.

Windows or my antivirus shows a warning. Is something wrong?

No. Internet Guardian is a new tool and isn't digitally signed yet, so some Windows and antivirus warnings can appear. It starts from plain-text scripts you can open and read in Notepad. If Windows says "Windows protected your PC", click "More info", then "Run anyway". If an antivirus asks, choose "Allow". The check itself changes nothing.

Why does it ask for Administrator permission?

Only to fix things. The check runs without it. When you say Yes to a fix, Windows asks for permission and a separate window does the repair.

Will it restart my laptop?

Only the rare, deeper fixes need a restart. You get a clear warning first and you choose when. After restarting, run Internet Guardian again and the report tells you whether the fix worked.

Can I undo a fix?

Yes. Double-click "UNDO-LAST-FIX" on the USB and your saved settings are put back. The clock correction and the deeper resets can't be undone.

What if the problem is my internet provider?

The report says when the laptop looks fine and the problem is beyond it, so you know to restart the router or call the provider.

Does it need the internet?

No. It works when the connection is down, which is when it is most useful. When the internet is up, it makes a few small test connections.

Can I copy it to another USB stick?

Each Internet Guardian is licensed to its own USB stick and won't start from a different drive.

Which Windows versions does it support?

Windows 10 and 11. Windows in S mode, and locked-down work laptops that block scripts, aren't supported.
